LUNA SCOUT - COMPLETE UPDATED PROJECT

This is the full project, with all previous updates already included.
You do not need an earlier ZIP or a separate data folder.

1. Extract this ZIP completely into a NEW folder.
2. Open the extracted luna-scout folder.
3. Install 64-bit Python 3.11 or 3.12 if needed.
4. On Windows, double-click start_windows.bat.
5. Open http://127.0.0.1:8000 in Chrome, Edge or Firefox.
6. Keep the terminal open while using the application.

The first dependency installation needs an internet connection.
